Codex desktop manager

Install once. Start Codex immediately.

Volcengine Agent is a Codex++ based desktop manager customized for the volcengine.org relay. Enter your API key after installation and start coding with the bundled Codex CLI.

Download Releases View on GitHub

One relay

The app exposes only the Volcengine connection to keep setup focused.

Codex included

Release installers package the Codex CLI so it is ready after installation.

Local settings

API keys, models, and connection settings stay on your machine.

Relay endpoint

https://api.volcengine.org/v1

Get started

  1. Download the package for your system.
  2. Open Volcengine Agent and enter your Volcengine API key.
  3. Choose a model and launch the bundled Codex.

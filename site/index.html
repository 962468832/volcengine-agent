Volcengine AgentEnglish
Codex desktop manager

安装完成，直接使用内置 Codex。

Volcengine Agent 是基于 Codex++ 定制的桌面管理器，只连接 volcengine.org 中转 API。下载安装包后填写 API Key，即可开始使用。

下载 Releases 查看 GitHub

固定中转站

应用只提供 Volcengine 连接，避免误选其他服务商。

内置 Codex CLI

发行版会把 Codex CLI 一起打包，安装后即可启动。

本机配置

API Key、模型和连接设置保存在本机。

连接地址

https://api.volcengine.org/v1

使用步骤

  1. 下载对应系统的安装包。
  2. 打开 Volcengine Agent，填写 Volcengine API Key。
  3. 选择可用模型并启动内置 Codex。
